THE DECISION
Do not learn a new stack and start over. Keep the production experience in JavaScript/TypeScript, turn it into a credible backend-engineering identity, add PostgreSQL / Redis / cloud / testing, and use AI integration as the differentiator. Run India as the main funnel while testing UAE, India-eligible remote, and selective Saudi roles.

What to learn deeply

  • Advanced TypeScript — generics, narrowing, utility types, error modeling, clean interfaces.
  • Node.js internals — event loop, async patterns, streams, worker threads at a conceptual level, memory/performance troubleshooting.
  • PostgreSQL — joins, indexes, transactions/isolation, normalization, query plans, pagination, locking, practical optimization.
  • Redis — caching, TTL, distributed locks conceptually, rate limiting, queues/job state.
  • Backend architecture — modular monolith first, service boundaries, retries, idempotency, eventual consistency, API security.
  • Docker + AWS — containerize, deploy, logs/metrics, IAM basics, RDS/S3/SQS/ECS/ECR/CloudWatch.
  • Testing — Jest unit/integration tests, API contract thinking, Playwright for one e2e path.
  • AI application engineering — one reliable RAG system and one tool-using workflow; production concerns, not ML math.
  • DSA — arrays/hash maps, strings, two pointers, sliding window, stacks/queues, trees, graph basics, binary search, heaps, recursion/backtracking, intervals, basic DP.
  • Communication — concise project explanations and STAR answers.

What NOT to prioritize yet

  • Deep Kubernetes administration and platform engineering.
  • Java/Spring Boot or .NET/C# from zero as a primary stack.
  • Fine-tuning foundation models, advanced ML math, CUDA/GPU engineering.
  • Five AI frameworks at surface level — one production-quality AI integration is worth more.
  • Dozens of toy CRUD repositories.

Portfolio projects

Project 1 — Multi-tenant production SaaS backend

A realistic B2B workflow platform: Node/TypeScript, NestJS or clean Express, PostgreSQL/Prisma, Redis, background jobs, S3, WebSockets, Docker, AWS, GitHub Actions. Multi-tenancy, RBAC, audit logs, rate limiting, idempotent webhook processing, file uploads, search/filtering, scheduled jobs, notifications, admin surface. API docs, integration tests, load/performance notes, an ADR.

Resume proof: "Designed and deployed a multi-tenant Node/TypeScript backend with PostgreSQL, Redis, background jobs, RBAC and automated deployment."

Project 2 — AI operations / knowledge assistant

Ingest documents, chunk and embed, store in pgvector, retrieve with filters, stream answers, attach citations, support tool/function calls, maintain tenant isolation, log latency/token usage, evaluate retrieval quality. TypeScript/Node for the service; Python optional, never required.

Resume proof: "Built a production-style RAG service with Node/TypeScript, vector search, retrieval evaluation, streaming responses, access control and cost/latency telemetry."

Project 3 — Harden your current CarCare project

Do not build another simple app. Improve API performance, add PostgreSQL as a reporting/analytical path, Redis caching, background jobs, tests, structured logging, CI/CD, Docker and an architecture document. Never expose proprietary work from your employer.

Job-search execution system

  • 20-25 high-fit applications/week once Month 2 begins — prioritize fit over volume.
  • 5 referral conversations/week — colleagues, alumni, engineers at target companies, community.
  • 10 recruiter / hiring-manager messages/week with a two-sentence pitch and one relevant proof project.
  • Track each application: title, company, location, source, required stack, date, resume version, response, interview stage, reason for rejection.

NEGOTIATION SCRIPT

"My current package is ₹3 LPA. For my next move I am targeting roles where I can contribute as a backend-focused software engineer in Node.js/TypeScript, with production API, database, cloud and AI-integration capability. Based on the scope of the role and current market, I am targeting roughly ₹12-15 LPA, with flexibility depending on responsibilities and the overall package."

Never justify a 300-400% hike. Justify through scope, skills, evidence and market level. Never fabricate current compensation, experience or production exposure.

Sponsorship & remote legality

  • UAE: standard employment visa is employer-applied; employers must obtain the work permit. The virtual-work residence route is for working outside the country, not a substitute for in-country sponsorship.
  • Saudi: non-Saudis need a work permit and employer employment; permanent/temporary work-visa processes exist via official platforms.
  • Remote from India: direct employment through an Indian entity, an Employer of Record, or contractor engagement. Apply where "India Remote" is explicit — never on a generic "remote" label.
  • Education risk (ongoing BCA): a screening risk at some companies, not proof you cannot reach ₹10-15 LPA. Compete on production experience, measurable work, portfolio depth and interview performance while continuing the degree.

What can prevent the target salary

  • Resume stays "MERN developer" with no measurable backend ownership.
  • Projects are CRUD clones with no performance / security / testing / cloud / architecture proof.
  • DSA is weak enough to fail coding rounds after recruiter screens.
  • You cannot explain current production work deeply — trade-offs, bugs, architecture, DB choices, performance fixes.
  • You apply indiscriminately and accumulate ATS rejections instead of testing a targeted thesis.
  • You claim AI/cloud expertise without building and debugging a working system.
  • Communication is unclear, especially project explanations and behavioral answers.
  • The ₹3 LPA anchors your negotiation instead of the role's scope and market band.
